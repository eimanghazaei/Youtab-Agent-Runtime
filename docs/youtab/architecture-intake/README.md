# Youtab Architecture Intake

This directory preserves owner-supplied architecture, computation-runtime,
reasoning, memory, multi-agent, study, guide, report, and build-prompt
artifacts exactly as received.

## Authority boundary

- Inclusion here records reference material for the Agent Runtime downstream.
- It does not accept, renumber, supersede, or amend Youtab Canon or an ADR.
- The normative Cognitive Authority, One Brain architecture, memory authority,
  policy, and final effect authorization remain in `youtab-ai-os`.
- Runtime implementation may consume only requirements that have been
  reconciled with the authoritative Canon and approved through the normal
  branch, test, review, and merge process.
- Reports, notes, studies, guides, and prompts remain non-normative even when
  they discuss an ADR.
